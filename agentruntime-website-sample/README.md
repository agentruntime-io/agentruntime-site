# AgentRuntime Multi-page Website Prototype

Open `index.html` in a browser.

## Pages
- `index.html` — Homepage and core positioning
- `platform.html` — Runtime and platform architecture
- `workflows.html` — Business workflow use cases
- `developers.html` — APIs, SDKs, MCP and execution lifecycle
- `enterprise.html` — Governance, approvals and operational control
- `company.html` — Company story and product principles
- `contact.html` — Conversation and workflow intake

## Before production
- Replace conceptual visuals with real product screenshots or demos.
- Connect the contact form to a real backend or booking page.
- Add privacy, terms and security pages.
- Add verified customer proof and metrics.
- Review feature statements against the current shipped product.
- Add analytics, SEO/social metadata and a favicon.
